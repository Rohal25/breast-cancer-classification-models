Dataset: Breast Cancer Wisconsin Diagnostic (WDBC)
Source: UCI Machine Learning Repository
File: wdbc.data

This project includes the original dataset file in this folder. The Jupyter Notebook reads this local file, assigns descriptive column names, performs exploratory analysis and preprocessing, trains five classifiers, and saves the trained models and test/evaluation CSV files. No train.py script is required; model training is performed in assignment2.ipynb.
